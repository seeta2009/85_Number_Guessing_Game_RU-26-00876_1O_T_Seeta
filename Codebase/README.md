Number Guessing Game

This is a Python-based console game in which the computer generates a random number between 1 and 100. The player gets five attempts to guess the correct number.

Features

- Random number generation
- Five guessing attempts
- Too High and Too Low hints
- Input validation
- Play Again option

Technologies Used

- Python 3

Concepts Used

- Functions
- Loops
- Conditional Statements
- Random Module
- Exception Handling

How to Run

1. Install Python 3.
2. Open the project in VS Code.
3. Run "num_guessing_game.py".
4. Enter a whole number between 1 and 100.
